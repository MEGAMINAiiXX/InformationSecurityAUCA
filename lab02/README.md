# Lab 2 — Custom UNIX-based commands

## Цель

Создать небольшие Bash-скрипты, объединяющие стандартные команды Linux.

## Скрипты

| Скрипт | Назначение |
|---|---|
| `greet.sh` | Приветствует текущего пользователя |
| `current_time.sh` | Показывает время и время до окончания рабочего дня |
| `count_word.sh` | Считает буквальные вхождения слова в текстовом файле |
| `delete_empty_files.sh` | Находит и удаляет пустые файлы верхнего уровня указанного каталога |
| `system_info.sh` | Показывает имя узла, пользователя и свободное место |

## Запуск

```bash
chmod +x ./*.sh
./greet.sh
./current_time.sh
./count_word.sh sample.txt Linux
./delete_empty_files.sh empty-test
./system_info.sh
```

`delete_empty_files.sh` требует явно передать каталог, проверяет его существование и не обходит вложенные каталоги. Для упражнения создайте отдельную тестовую папку и не указывайте домашний или системный каталог.

Рабочий день в примере заканчивается в 17:00. Для подсчёта слов используется `grep -oF`, поэтому аргумент слова трактуется буквально, а не как регулярное выражение.
