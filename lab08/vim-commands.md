# Vim quick reference

| Действие | Команда |
|---|---|
| Перейти в normal mode | `Esc` |
| Начать ввод перед курсором | `i` |
| Добавить текст в конец строки | `A` |
| Открыть новую строку ниже | `o` |
| Удалить строку | `dd` |
| Копировать строку | `yy` |
| Вставить строку | `p` |
| Отменить действие | `u` |
| Повторить отменённое действие | `Ctrl-r` |
| Найти текст | `/текст`, затем `n` / `N` |
| Перейти к строке | `:номер` |
| Сохранить | `:w` |
| Выйти | `:q` |
| Сохранить и выйти | `:wq` |
| Выйти без сохранения | `:q!` |
| Удалить весь текст текущего буфера | `:%d` |

Проверяйте имя файла перед командами сохранения и используйте копию для экспериментов.
