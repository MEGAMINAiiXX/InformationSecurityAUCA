# Lab 13 — Keyloggers and protection

## Цель

Понять, почему скрытая запись нажатий и отправка журналов нарушают приватность, и исследовать безопасную обработку ввода внутри явно выбранного поля.

Вместо глобального перехвата клавиатуры страница `demo.html` обрабатывает стандартное событие `input` только в видимом текстовом поле. Она показывает лишь количество символов, не отображает содержимое, не сохраняет его в файл или браузерное хранилище и ничего не отправляет по сети.

## Запуск и проверка

Откройте `demo.html` в браузере и введите тестовый текст в поле. Проверьте код: слушатель привязан только к текстовой области; в проекте нет фонового процесса, файлового журнала или сетевого endpoint для ввода.

## Защита

- Используйте обновлённое защитное ПО и устанавливайте приложения только из доверенных источников.
- Не запускайте неизвестные вложения и скрипты.
- Не вводите секреты на подозрительных страницах.
- Для рабочей станции применяйте принцип наименьших привилегий и многофакторную аутентификацию.
