# Information Security Labs

![Validation](https://github.com/MEGAMINAiiXX/InformationSecurityAUCA/actions/workflows/validate.yml/badge.svg)

Практические лабораторные работы по Linux, Unix-командам и основам информационной безопасности. Материалы рассчитаны на запуск в Ubuntu или WSL и включают инструкции, учебные примеры и проверки.

## Быстрый старт

```bash
git clone https://github.com/MEGAMINAiiXX/InformationSecurityAUCA.git
cd InformationSecurityAUCA
./validate.sh
```

Для отдельных скриптов может понадобиться сделать файл исполняемым командой `chmod +x path/to/script.sh`. Дополнительные зависимости и команды установки указаны в README соответствующей лабораторной.

## Требования

- Ubuntu или WSL с Bash
- Python 3
- Для Lab 10: NGINX
- Для Lab 11: `make` и C-компилятор, например GCC

## Проверки

Запустите полный набор проверок из корня репозитория:

```bash
./validate.sh
```

Скрипт проверяет синтаксис Bash и Python, запускает модульные тесты, выполняет безопасные локальные проверки перемещения файлов и архивации, проверяет NGINX-прокси (если NGINX установлен) и собирает C-пример (если доступны `make` и компилятор). Временные тестовые файлы удаляются после проверки.

## Безопасность

Практические примеры предназначены для собственного локального учебного окружения. Lab 4, 12 и 13 оформлены как защитные упражнения: репозиторий не собирает и не отправляет пароли или платёжные данные, не автоматизирует подбор учётных данных и не записывает нажатия клавиш в фоне.

Команды, меняющие системные учётные записи, пакеты или расписание cron, приведены для самостоятельного выполнения и не запускаются автоматически.
