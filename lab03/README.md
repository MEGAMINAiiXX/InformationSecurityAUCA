# Lab 3 — Toy shell

## Цель

Сделать интерактивную Python-программу, которая выводит файлы и каталоги текущей папки с временем изменения раньше введённой даты `YYYY-MM-DD`.

## Запуск

```bash
python3 toy_shell.py
```

Введите дату, например `2024-01-01`; команда `exit` завершает программу. Для проверки создайте тестовый файл, установите ему старую дату командой `touch -d '2020-01-01' old.txt`, затем запустите оболочку из этой папки.

На Linux `ctime` означает время последнего изменения метаданных, а не гарантированное время создания. Поэтому программа использует `mtime` — переносимое время последнего изменения содержимого — и явно называет его в выводе.
