# Lab 8 — Vim editor

## Практика

Откройте тренировочный файл:

```bash
vim practice.txt
```

Повторите действия из шпаргалки [`vim-commands.md`](./vim-commands.md), сохраните изменения и выйдите. Чтобы не менять оригинал, можно открыть временную копию:

```bash
cp practice.txt /tmp/lab08-practice.txt
vim /tmp/lab08-practice.txt
```

Если Vim отсутствует в Ubuntu/WSL: `sudo apt update && sudo apt install vim`.
