# Lab 12 — Brute-force attacks: defensive exercise

## Цель

Понять, почему личные сведения (имя, даты и другие известные факты) делают пароли предсказуемыми, и изучить защитную реакцию на повторные неудачные попытки.

В исходном задании есть инструкция по автоматизированному подбору паролей. Здесь она заменена локальной симуляцией защиты: программа не отправляет сетевые запросы, не перебирает кандидатов и не взаимодействует с реальными аккаунтами.

## Проверка пароля

```bash
python3 password_policy.py
```

Введите только вымышленный пароль: ввод скрыт, пароль не сохраняется и не отправляется. Дополнительно можно указать тестовые персональные подсказки:

```bash
python3 password_policy.py --hint "Alex" --hint "2001"
```

## Симуляция блокировки

```bash
python3 login_defense.py
```

Используйте вымышленные значения `demo` и `not-a-real-account`; после трёх ошибок вход временно блокируется. Это иллюстрация защитного контроля, а не инструмент подбора.

## Автотесты

```bash
python3 -m unittest -v test_password_policy.py
```
