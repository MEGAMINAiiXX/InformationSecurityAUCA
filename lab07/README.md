# Lab 7 — Crontab in Linux

## Цель

Понять пять полей cron и запустить безопасный локальный Python-скрипт, который добавляет временную метку в указанный файл.

## Сначала проверьте вручную

```bash
python3 write_timestamp.py /tmp/lab07-cron-demo.log
cat /tmp/lab07-cron-demo.log
```

## Необязательное расписание

Получите абсолютный путь к скрипту командой `realpath write_timestamp.py`, затем откройте `crontab -e` и добавьте строку, заменив пути на свои:

```cron
* * * * * /usr/bin/python3 /absolute/path/write_timestamp.py /tmp/lab07-cron-demo.log
```

Через минуту проверьте файл и список задач командой `crontab -l`. После упражнения удалите только добавленную строку в `crontab -e`; для файла примера используйте `rm /tmp/lab07-cron-demo.log`.

Задача намеренно пишет только локальную временную метку, не отправляет почту или данные по сети и не устанавливается в cron автоматически.
