# Lab 4 — Comprehending phishing

## Цель

Распознавать фишинговые признаки: срочность и угрозы, неожиданные ссылки, запросы пароля или платёжных данных, несоответствие домена и просьбы обойти обычные процедуры.

## Практика

`examples/messages.json` содержит только вымышленные учебные сообщения. Проверьте их локально:

```bash
python3 analyze_message.py examples/messages.json
```

Анализатор выводит признаки для обсуждения и не открывает ссылки, не отправляет сообщения, не собирает данные и не подключается к сети. Результат эвристический: отсутствие срабатываний не доказывает подлинность письма.

В исходном задании предлагалось собирать и сохранять пароли или данные карты под видом страницы входа. Вместо этого лабораторная сохраняет учебную цель — понять методы социальной инженерии — без имитации реального бренда, формы оплаты или сбора секретов.

## Вопросы

1. Какие признаки в каждом сообщении вызывают подозрение?
2. Как независимо проверить домен и отправителя?
3. Куда безопасно сообщить о подозрительном письме?
